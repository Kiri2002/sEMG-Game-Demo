# sEMG-Game-Demo
A game demo controllered by real-time surface electromyography (sEMG) signals — course project

## Overview

Conventional game controllers rely on hand and finger movements. This project explores an
alternative input modality: reading electrical activity from muscles and mapping it to
in-game actions.

The system acquires sEMG signals from electrodes, performs real-time signal
processing and feature extraction, classifies muscle activation patterns, and translates
them into keyboard/game events.
